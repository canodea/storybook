Ekranın ortasında karar isteyen modal: işlem onayı, silme/iptal, oturum uyarısı, kritik bilgi. Stacked alt alta (uzun etiketler, varsayılan), Inline yan yana (VAZGEÇ / ONAYLA) düzenindedir. Primary olumlu ana aksiyon, Secondary vazgeç (gizlenebilir → tek butonlu bilgilendirme). **Media=Icon** iken Security setinden Info / Warning / ShieldCheck ikonu (32 px), **Media=Illustration** iken 120×120 illüstrasyon gösterilir. **Show Media** medyayı tamamen gizler.

## Playground

Figma'daki özelliklerin aynısı; **Media** ikon ile illüstrasyon arasında geçiş yapar, **Show Media** medyayı gizler, **Icon** / **Illustration** seçimi ilgili medyayı değiştirir, **Theme** kontrolü koyu temayı gösterir.

## Kullanım

- İşlem onayı, silme/iptal, oturum uyarısı ve kritik bilgi gibi karar isteyen anlarda kullanılır.
- `title` soru/sonuç cümlesi, `message` somut detay olur; olumlu ana aksiyon `primaryLabel`, vazgeç `secondaryLabel`.
- Uzun etiketlerde `actions="stacked"` (varsayılan), kısa etiketlerde `actions="inline"`; tek butonlu bilgilendirmede `secondaryAction={false}`.
- Medya için `media="icon"` + `iconAsset` ya da `media="illustration"` + `illustration` seçilir; gerekmiyorsa `showMedia={false}`. Ekranın üstünde açılacaksa `open` verilir.
